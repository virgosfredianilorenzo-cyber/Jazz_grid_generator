Introduction & vue d'ensemble

Jazz Chart Editor v2 est un outil web dédié à la création et à l'édition de grilles d'accords jazz. Il permet d'importer des fichiers MusicXML, d'annoter chaque accord avec des données théoriques (modes, arpèges, tensions), de transposer l'ensemble de la grille et d'imprimer une partition claire pour le pupitre.

📂
Import MusicXML
Chargez n'importe quel fichier MusicXML depuis votre logiciel de notation.
✏️
Édition intuitive
Cliquez sur un accord pour l'éditer, ajouter ou supprimer des mesures.
🎹
Théorie musicale
Modes, arpèges, renversements et tensions disponibles par accord.
🎵
Transposition
Transposez par demi-ton ou directement vers une tonalité cible.
🖨️
Impression optimisée
Thème clair/sombre, contraste ajustable, couleurs par section.
🌐
4 langues
Interface disponible en français, espagnol, italien et anglais.
2🚀

Démarrage rapide

Option A — Créer une nouvelle grille

Cliquez sur ✨ Nouveau dans la barre d'outils. Une grille vierge de 8 mesures en Do majeur est créée.
Modifiez le titre, la tonalité, le tempo et le style dans l'en-tête du document.
Cliquez sur un accord pour l'éditer, ou sur le bouton + d'une mesure pour en ajouter un nouveau.

Option B — Importer un fichier MusicXML

Cliquez sur 📂 Ouvrir MusicXML ou glissez-déposez un fichier .musicxml / .xml dans la zone centrale.
La grille est analysée et affichée automatiquement avec les accords, sections et répétitions détectés.
Editez librement la grille importée : ajoutez des annotations, transposez, imprimez.
💡 Astuce : Vous pouvez exporter votre travail en JSON pour le recharger ultérieurement, même sur un autre appareil.

Édition d'une grille

En-tête du document

Le champ titre est directement éditable en cliquant dessus. Les champs tonalité, tempo, mesure et style se trouvent en dessous et sont librement modifiables.

Mesures

Chaque mesure affiche son numéro en haut à gauche. Les mesures avec barres de reprise sont signalées par une double barre en or sur le bord gauche ||: ou droit :||.

Au survol d'une mesure apparaissent deux boutons discrets :

ActionDéclencheur
Supprimer la mesureBouton ✕ en haut à droite
Dupliquer la mesureBouton ⧉ en haut à droite
Ajouter un accordBouton + à droite des accords
Éditer rapidementClic droit sur la mesure
5🎸

Gestion des accords

Fenêtre d'édition d'accord

Un clic sur un accord ouvre la fenêtre d'édition. Vous pouvez :

Choisir la fondamentale parmi les 17 notes disponibles (avec enharmoniques).
Choisir la qualité : majeur, mineur, dominant, diminué, augmenté, sus, etc. (24 qualités).
Ajouter des tensions/options : b5, #5, b9, #9, #11, b13, add9, add11, omit3.
Saisir une basse en slash (ex. G pour C/G), ou un accord libre en texte brut (ex. Cmaj7#11).
Définir la durée en temps (nombre de temps que l'accord occupe dans la mesure).

Annotations théoriques

Chaque accord peut recevoir une annotation théorique riche. Cliquez sur l'icône ✏️ qui apparaît au survol d'un accord pour ouvrir le panneau d'annotation.

Sections disponibles

Annotations de section

Un champ de texte libre est disponible sous le label de chaque section (ex : "Thème principal", "Solos 4x"). Il est affiché visuellement dans la grille.

🎸 Pour les bassistes : L'affichage des renversements d'arpège est particulièrement utile pour visualiser les positions sur une basse 4 ou 5 cordes.
7🎵

Transposition

Le groupe de transposition se trouve dans la barre d'outils principale.

Par demi-ton

Utilisez les boutons − et + pour descendre ou monter d'un demi-ton. Le compteur affiche l'écart cumulé (ex : +3).

Vers une tonalité cible

Sélectionnez directement la tonalité de destination dans le menu déroulant (Db, F#, etc.).

Réinitialiser

Cliquez sur le bouton ↺ pour revenir à la tonalité d'origine. Toutes les modifications de transposition sont annulées.
💡 La transposition respecte les enharmoniques selon la tonalité de destination (ex : F# → Si♭ s'écrit B♭, pas A#).

Introduction & overview

Jazz Chart Editor v2 is a web tool dedicated to creating and editing jazz chord charts. It lets you import MusicXML files, annotate each chord with theoretical data (modes, arpeggios, tensions), transpose the entire chart, and print a clean lead sheet for the music stand.

📂
MusicXML Import
Load any MusicXML file from your notation software.
✏️
Intuitive editing
Click a chord to edit it; add or delete measures on the fly.
🎹
Music theory
Modes, arpeggios, inversions, and tensions per chord.
🎵
Transposition
Transpose by semitone or directly to a target key.
🖨️
Print-ready
Light/dark theme, adjustable contrast, per-section colors.
🌐
4 languages
UI available in French, Spanish, Italian, and English.
2🚀

Quick start

Option A — Create a new chart

Click ✨ New in the toolbar. A blank 8-measure chart in C major is created.
Edit the title, key, tempo and style in the document header.
Click any chord to edit it, or click the + button in a measure to add a new chord.

Option B — Import a MusicXML file

Click 📂 Open MusicXML or drag and drop a .musicxml / .xml file onto the central drop zone.
The chart is parsed and displayed automatically with detected chords, sections, and repeat barlines.
Freely edit the imported chart: add annotations, transpose, print.
💡 Tip: Export your work as JSON to reload it later, even on a different device.

Transposition

Use the − and + buttons to move down or up by one semitone. The counter shows the cumulative offset (e.g. +3).
Or select the target key directly from the dropdown (e.g. Bb, F#).
Click ↺ to reset to the original key.
💡 Transposition respects enharmonic spelling based on the destination key (e.g. F# → Bb is written as B♭, not A#).
